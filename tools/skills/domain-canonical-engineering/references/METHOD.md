# Canonical Domain Engineering --- Method Map

This reference is the short operational map behind the full skill.

## The two problems

``` text
Deep layer                         Operational layer
------------------------------     ------------------------------
preserve architecture              retrieve architecture at decision time
preserve rationale                 challenge material choices
preserve uncertainty               disclose unresolved constraints
preserve negative knowledge        prevent repeated known mistakes
survive lost conversation          support independent verification
```

A mature canonical needs both.

## Construction sequence

``` text
1. Discover the domain from concrete requirements/evidence
2. Establish domain authority and boundary
3. Classify knowledge
4. Extract capabilities/responsibilities/invariants
5. Record accepted decisions + rationale
6. Preserve rejected paths worth remembering
7. Preserve deliberately open decisions
8. Build the self-sufficient deep canonical
9. Derive the executor's cognitive decision progression
10. Compress critical constraints into an execution control surface
11. Link every compressed control back to deep references
12. Define how an executor uses the document
13. Define independent verification where justified
14. Trial the canonical with a capable executor
15. Observe reminders, misses, violations, and retrieval failures
16. Refine the document from observed execution evidence
```

## Knowledge classification

``` text
ACCEPTED / FROZEN
CONTEXT
EVIDENCE
PROPOSAL / CANDIDATE
OPEN / UNRESOLVED
REJECTED / CORRECTED
```

Do not let these collapse into undifferentiated prose.

## Control-surface derivation

Do not decide "we need 10 checks" in advance.

Instead:

``` text
deep canonical
      ↓
extract normative invariants
      ↓
group semantically
      ↓
order by executor cognition
      ↓
write compressed challenge + required property
      ↓
attach deep references
      ↓
audit coverage both directions
```

## Trial question

After giving the canonical to an executor, record every moment where you
had to say:

> "The canonical already says this."

Those moments are evidence of retrieval/control-surface weakness even if
the deep document was semantically correct.

## Maturity question

> Can a competent actor who never saw the original conversation continue
> the domain safely and make material decisions without repeated
> reminders of documented invariants?
