# PIP-0001 — Refresh the first capability execution plan

Status: active — documentation rewrite; independent review pending.

## Motivation

The first capability plan predates the current canonical package. It points to
retired paths and Primitives v1.4, conflates architectural invariants with local
qualification choices, and omits the current PIP and Counter-Proof workflow.
The user requested a rewrite grounded in the README and current canonicals.
This is material documentation work because it changes maintained execution
guidance; it does not authorize implementation of the capability.

## Proposed change

Rewrite [the plan](../PIP-0003/PIP-0003.md) in place. Preserve useful
research in a separately identified historical candidate worksheet, distinguish
accepted architecture from delivery choices and open decisions, and define
evidence-based implementation and review gates. Repair directly related research
links. Record an executor assessment of the documentation artifact.

## Scope

The plan, its supporting research navigation, and this work's provenance records.
No production code, dependency selection, canonical revision, capability
implementation, external submission, or independent-review verdict is included.
Future capability implementation requires its own PIP; this PIP identifies the
documentation rewrite only.
